### What it is
A layered defensive visibility suite that shows authorised operators **what is stored, running, and communicating** on their own devices and infrastructure — without decrypting content or bypassing platform protections.

### The Three Shields

**Endpoint Shield** (teal)  
File integrity · Entropy · Hidden attributes · Persistence inventory  
Windows · macOS · Linux · Mobile

**Edge Shield** (blue)  
Hypervisors · Virtual disks · Browser storage · Shared-folder monitoring  
ESXi · KVM · Browsers · Games

**Data Shield** (purple)  
Process network bytes · Message/frame counts · Path mapping · Device ID  
Telemetry · Attribution

### Key product surfaces
- Dashboard + Live grid + Live map  
- Guide AI (threat levels: everyday / elevated / stalking / child)  
- Family Link (always visible, child can unlink)  
- Panic lock & sharing controls  
- Real scan history (nothing invented)  
- Optional add-ons: Realtime AV, Network Ops, Family Link, Breach Watch, Concierge

### Boundaries (non-negotiable)
- No decryption or unlocking of protected content  
- No bypass of passwords, encryption, or platform sandboxes  
- No tools for unauthorised access to other people’s data  
- Diagnostics & support sessions require explicit user Allow  
- Guide AI refuses attack / exploitation advice
