## What this is

Shield Systems is a **defensive visibility** platform. It helps operators understand:

- What is stored on their systems  
- What is running and persisting  
- What is communicating (and from which process / device)

It does **not** decrypt content, unlock passwords, or bypass platform sandboxes.

### The three shields

| Shield | Focus |
|--------|--------|
| **Endpoint Shield** | File integrity, entropy checks, hidden attributes, persistence inventory (Windows, macOS, Linux, mobile) |
| **Edge Shield** | Hypervisors, virtual disks, browser storage, shared-folder monitoring |
| **Data Shield** | Process-level network bytes, message/frame counts, storage-path mapping, device identity attribution |

### Coverage

- Desktop & server OS (Windows, macOS, Linux)  
- Mobile (iOS / Android) within normal sandbox & MDM constraints  
- Virtualisation layers  
- Major browsers (local storage, service workers where permitted)  
- Common gaming client libraries (with coexistence rules for legitimate anti-cheat)

---

## Clear boundaries

- No decryption or unlocking of protected content  
- No bypass of passwords, encryption, or platform sandboxes  
- No tools for unauthorised access to other people’s data  
- Use must comply with law, policy, and platform terms
